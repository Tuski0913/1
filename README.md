# 中国人口版图 · 数据驾驶舱

展示中国大陆 31 省级行政区的人口、人口密度和省际流动。页面和数据均为静态文件，可部署到 GitHub Pages，无需后端。

## 本地预览

在本目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000/`。手机竖屏以原尺寸显示大屏，可横向及纵向滚动；横屏或桌面窗口按设计尺寸等比缩放。

## 数据来源与口径

- 年末常住人口：课程数据标注来源为《中国人口和就业统计年鉴 2024》，1990–2023 年，单位为万人。面板缺失值保留为 `null`，未插值。全国合计仅在 31 省数据均齐全时绘制。
- 省际流动：课程数据标注来源为第七次全国人口普查，2020 年户籍地到现住地的省际流动存量，单位为人，并非年度迁移量。省级净流入为迁入减迁出，图表单位为万人。
- 人口密度：2020 年人口除以等积投影面积，单位为人/km²。
- 人口分型：课程提供的预计算 K-Means 聚类，指标为 2010–2020 年人口增长率、净流入率和密度。页面分型视图目前保留为空容器。
- 地图：课程素材 `china.js` 标注来源为 DataV.GeoAtlas；图中 31 省为统计范围。

`data.js` 包含可下载的省级时间序列和 930 条省际 OD 汇总记录。数据及地图素材的再发布授权尚待核实，来源说明不等同于使用许可。
