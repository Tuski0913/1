# 中国主要城市通勤监测驾驶舱

交互展示 45 个主要城市 2022—2024 年的通勤指标。页面使用本地 ECharts 和地图文件，无服务端和密钥。

## 数据来源

- 中国城市规划设计研究院《2025年中国主要城市通勤监测报告》（发布版 V20251229），调查期为 2024 年 9—11 月；指标源自百度地图位置服务和移动通信运营商手机信令。项目数据为课程包整理的报告指标，不包含报告原始 PDF。
- 城市常住人口等背景数据参考第七次全国人口普查，用于加权。
- 中国省级地图数据文件注释标注来源为 DataV.GeoAtlas；ECharts 文件内包含 Apache License 2.0 版权声明。地图和数据公开再分发的授权及来源仍需发布者核实。

## 口径和已知限制

- 研究对象为 45 个城市中心城建成区通勤人口，不代表全市域全部人口。指标及地图仅用于展示与研究交流。
- 总体人口加权使用七普市域常住人口作为代理权重，可近似复现报告总体值；报告的分规模均值是算术平均，不能与人口加权分组均值视为同一口径。切换口径时应明确标注。
- 数据为 2022、2023、2024 年；缺失保持 null，不以 0 填补，不进入均值和排名。2022 年轨道覆盖数据全部缺失；海口、银川、西宁的轨道覆盖指标无值。
- 通勤空间半径是中性空间尺度，不可按数值大小直接判定优劣。中性指标按数值排列仅表示大小。
- 分型基于 2024 年 7 个有方向且完整的指标进行 K-Means 聚类，聚类标签是相对分类，不是因果判断。
- 45 城分组采用城市名单中的 7/15/13/10；报告选取图的柱状标签为 7/14/14/10，存在不一致。

## 运行

将本目录内容放在静态网站根目录，或在本目录运行 `python -m http.server 8000`，访问 `http://localhost:8000/`。
